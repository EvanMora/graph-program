# Graph Program

## How to run
### Compile: 
'''bash
javac -cp "./lib/*" -d bin src/*.java src/domain/*.java
'''
### Execute:
'''bash
java -cp "bin:./lib/*" Main
'''
### Script (Compile and Execute the program):
'''bash
bash run.sh
'''
*NOTE:* Run this comands on the root of the proyect

## Dependencies
- flatlaf 3.7.1
